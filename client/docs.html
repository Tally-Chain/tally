How the testnet works

Docs

Tally is a public proof-of-work chain. A payment is a receipt: who paid, who was paid, the amount, the words, and an optional mark. Both sides read those bytes from the block. This page is the rule the wallet and the node share.

Addresses

A wallet is one 32-byte seed. The seed is an ed25519 secret. The address is tally1 plus the base58 of the public key and a 4-byte checksum. Keys are made in the browser.

A receipt

A pay transaction carries the payer, the payee, the amount, a fee, a nonce, the words, and an optional mark. The words are one line, 1 to 140 bytes. The mark, if present, is 64 hex characters: the hash of a file or a post that stays off the chain. The notch is SHA-256 of the words. The signature covers the canonical lines, so a changed word, amount, or mark will not verify.

The minimum fee is 0.01 tTALLY. 1 tTALLY is 1,000,000 notches. The fee goes to the miner of the block.

Faucet

Once an hour an address may sign a faucet receipt for 25 tTALLY. The chain mints those coins. The memo is the word faucet. tTALLY has no market value.

Mining

The header is hashed with SHA-256. A block is valid when the hash is below 2^256 / difficulty. Difficulty retargets every block toward 20 seconds, and it cannot move by more than 4× in one step. The reward is 8 tTALLY plus the fees in that block. It can be spent after 3 further blocks. The public node mines slowly so other miners can win.

SHA-256 is the testnet hash because the same function runs in the browser and on the node. A memory-hard hash is a later choice if specialized hardware crowds browsers out. The receipt rules do not depend on it.

API

GET  /api/stats
GET  /api/blocks?limit=12&before=N
GET  /api/block/:height|:hash
GET  /api/receipts?limit=12
GET  /api/tx/:id
GET  /api/account/:address
GET  /api/search?q=
GET  /api/work?address=tally1…
POST /api/work   { id, nonce }
POST /api/tx     { tx }

Run a node

cd tally
npm install
npm start          # http://localhost:8344

Environment: PORT, DATA_PATH, NODE_PAUSE (milliseconds the public node waits between hash batches), MINER_SEED (64 hex, optional).

Mine from the command line

node miner/miner.js YOUR_TALLY1_ADDRESS --node http://localhost:8344
